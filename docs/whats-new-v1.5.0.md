# What’s new in Emotion Wheel 1.5.0

Released 5 October 2026.

If this browser was previously connected to Google, a banner at the top now asks you to reconnect after reopening the page or when the connection expires. Choose Reconnect Google to open sign-in. The banner disappears once connected and remains available if sign-in is cancelled or fails. Browsers that have never connected do not see the reminder.

Existing saved sync or shared-file account information also enables the reminder. A new local flag remembers only whether Google was connected, without saving an access token or account details. Automatic sync still requires Start Sync after reconnection.

Help and Privacy explain this behaviour. Local records, Drive files and the record schema are unchanged.
