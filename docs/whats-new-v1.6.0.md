# What’s new in Emotion Wheel 1.6.0

Released 5 October 2026.

- **Reconnect on the current page:** Reconnect Google keeps your current Emotion Wheel page open. Connection feedback appears above the content. When a sync choice is needed, the prompt appears there and receives keyboard focus.
- **Fewer steps to resume sync:** Start Sync remembers your choice for the Google account and current file in this browser. After reconnecting to that same verified account and existing file, automatic sync resumes using the saved comparison copy and normal conflict protection. Pause Sync turns off automatic resumption.
- **Review when needed:** Different accounts or files, missing comparison copies, unresolved sync issues, unfinished edits or rating reviews, data upgrades and shared-data contexts do not resume automatically. No replacement file is created by automatic resumption.
- **Clearer Help:** Google access is temporary and needs renewing regularly. Refreshing or closing the page also clears the in-memory connection. Help explains these limits, the reconnect reminder, saved sync preferences and the difference between reconnection and temporary network retries. Privacy describes the stored account/file preference.

Existing records, record schema and backup format are unchanged. Existing browsers begin remembering the preference when Start Sync is selected in this version; a previous manual save alone does not turn on automatic sync.
